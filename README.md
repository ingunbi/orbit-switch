# Orbit Switch

두 개의 궤도 사이를 전환하며 붉은 파편을 피하고 에너지를 모으는 짧은 우주 아케이드 게임입니다. 외부 이미지·폰트·CDN 없이 Vanilla JavaScript와 Canvas 2D로 실행됩니다.

## 실행

Node.js 22.12 이상을 권장합니다.

```sh
npm ci
npm run dev
```

표시되는 로컬 주소로 접속합니다. `npm run build`는 `dist/`를 만들고, `npm run preview`로 배포 빌드를 확인할 수 있습니다. 상대 경로 빌드이므로 `/games/orbit-switch/` 같은 하위 경로에서도 동작합니다.

## 조작과 규칙

- 화면 탭, **Space**, **↑ / ↓**: 안쪽·바깥쪽 궤도 전환
- **P / Esc**, 상단 일시정지 버튼: 일시정지·계속
- **M**, 상단 음표 버튼: 소리 켜기·끄기
- 붉은 파편에 부딪히면 항해가 끝납니다. 탐사선은 자동으로 공전합니다.
- 빛나는 에너지 수집은 25점부터 시작합니다. 3개 연속마다 배수가 증가해 최대 4배가 됩니다. 에너지를 놓치면 연속 수집이 초기화됩니다.
- 항해 시간과 피한 파편도 점수에 반영됩니다. 시간이 지날수록 공전과 파편 간격이 빨라집니다.
- 다른 탭이나 창으로 이동하면 자동 일시정지하며, 계속 버튼을 누르면 잠깐 준비 시간을 제공합니다.
- 최고 기록과 소리 설정은 브라우저 `localStorage`에 저장합니다. 저장이 막혀도 플레이할 수 있습니다. 소리는 기본적으로 꺼져 있습니다.

## 우주 연출과 사운드

- 20초마다 다섯 가지 성운·행성 테마가 순환하며 현재 섹터 이름을 표시합니다.
- 여러 깊이의 별빛, 궤도 전환 잔상, 수집 파동과 점수 표시, 배수 달성·섹터 진입 연출이 항해에 반응합니다.
- **M** 또는 음표 버튼을 켜면 방향감 있는 전환음, 수집·콤보 상승음, 충돌음과 조용한 배경 리듬이 재생됩니다. 배경 리듬은 일시정지·탭 이탈·종료 때 멈추고 재개 준비 시간이 끝난 뒤 다시 시작합니다.
- 시스템의 모션 감소 설정에서는 별빛 이동·파동 확대·점수 이동과 카드 진입 애니메이션을 줄입니다. 시각 효과 개수에는 상한이 있으며, 장식용 난수는 파편 생성과 분리되어 있습니다.
- 기존 충돌 판정, 점수·배수와 난이도 진행 규칙을 유지합니다. 외부 이미지나 음원 다운로드는 사용하지 않습니다.

## 확인 및 배포

```sh
npm test
npm run build
```

`wrangler.jsonc`는 Cloudflare Workers 정적 자산 배포용입니다. 별도 Wrangler 설치 또는 `npx wrangler deploy`로 `dist/`를 배포할 수 있습니다. 이 프로젝트 자체에는 계정 정보나 비밀 키가 포함되지 않습니다.

충돌 판정·전환 입력·난이도·배수 상한 외에 섹터 변화, 효과 상한·일시정지·모션 감소, 오디오 음소거·음악 재개·노드 정리를 Node.js 기본 테스트 러너로 검증합니다. 같은 시드로 진행한 항해가 모션 설정에 관계없이 같은 점수와 수집 결과를 내는지도 확인합니다.
