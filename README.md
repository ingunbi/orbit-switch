# Orbit Switch

두 개의 궤도 사이를 전환하며 붉은 파편을 피하고 에너지를 모으는 짧은 우주 아케이드 게임입니다. 외부 이미지·폰트·CDN 없이 Vanilla JavaScript와 Canvas 2D로 실행됩니다.

## 실행

Node.js 22.12 이상을 권장합니다.

```sh
npm ci
npm run dev
```

표시되는 로컬 주소로 접속합니다. `npm run build`는 `dist/`를 만들고, `npm run preview`로 배포 빌드를 확인할 수 있습니다. 상대 경로 빌드이므로 `/games/orbit-switch/` 같은 하위 경로에서도 동작합니다.

## 조작과 규칙

- 화면 탭, **Space**, **↑ / ↓**: 안쪽·바깥쪽 궤도 전환
- **P / Esc**, 상단 일시정지 버튼: 일시정지·계속
- **M**, 상단 음표 버튼: 소리 켜기·끄기
- 탐사선은 자동으로 공전하며, 출발할 때 보호막 1회를 받습니다. 파편에 닿으면 보호막을 소모하고 연속 수집이 초기화됩니다. 보호막이 없을 때 다시 닿으면 항해가 끝납니다. 보호막 소모 직후에는 0.5초의 짧은 유예가 있습니다.
- 보호막이 없는 동안 에너지를 8개 모으면 재충전됩니다. 보호막은 최대 1회만 보유하며, 충전량을 HUD에서 확인할 수 있습니다.
- 첫 3개 접근 뒤에는 반대 궤도로 이어지는 **교차 2연타**와 같은 안전 궤도에 에너지 3개가 이어지는 **에너지 흐름** 패턴이 등장합니다. 모든 파편은 반 바퀴 앞에서 예고되며, 교차 접근 사이에는 0.72초의 간격이 있습니다.
- 파편이 다가올 때 마지막 순간에 위험 궤도에서 반대 궤도로 전환한 뒤 안전하게 통과하면 **퍼펙트 회피 +20점**을 받습니다. 너무 일찍 전환하거나 보호막으로 막은 파편에는 이 보너스가 붙지 않습니다.
- 빛나는 에너지 수집은 25점부터 시작합니다. 3개 연속마다 배수가 증가해 최대 4배가 됩니다. 에너지를 놓치면 연속 수집이 초기화됩니다.
- 항해 시간과 피한 파편도 점수에 반영됩니다. 시간이 지날수록 공전과 파편 간격이 빨라집니다.
- 다른 탭이나 창으로 이동하면 자동 일시정지하며, 계속 버튼을 누르면 잠깐 준비 시간을 제공합니다.
- 최고 기록과 소리 설정은 브라우저 `localStorage`에 저장합니다. 저장이 막혀도 플레이할 수 있습니다. 소리는 기본적으로 꺼져 있습니다.

## 우주 연출과 사운드

- 20초마다 다섯 가지 성운·행성 테마가 순환하며 현재 섹터 이름을 표시합니다. 성운과 행성색은 부드럽게 이어지고, 배경의 오로라와 유성이 공간감을 더합니다.
- 여러 깊이의 별빛, 궤도 전환 잔상, 수집 파동과 점수 표시, 배수 달성·섹터 진입 연출이 항해에 반응합니다. 최대 배수에서는 잔광과 배경 화음이 강화되고, 12개부터 추가 6개 연속 수집마다 MAX SIGNAL 연출이 나타납니다. 이 연출은 추가 점수를 주지 않습니다.
- 출발 때 짧은 워프와 상승음이 재생되며 바로 궤도를 전환할 수 있습니다. 수집한 에너지는 빛줄기로 계기판에 흡수되고 ENERGY 표시가 반응합니다. 점수와 수집량은 수집 순간에 반영됩니다.
- 성운 가스와 행성 구름은 로컬에서 생성한 작은 텍스처를 재사용합니다. 파편에는 균열·명암·짧은 잔광을, 탐사선과 에너지 결정에는 입체적인 재질을 적용했습니다. 텍스처 생성이 지원되지 않아도 기본 성운으로 플레이할 수 있습니다.
- 보호막이 없는 상태에서 충돌하면 점수와 항해 시간이 즉시 멈추고, 약 0.62초의 파편·충격파 연출 후 결과가 표시됩니다. 작은 화면 흔들림은 최대 3px로 제한합니다. 보호막이 막은 충돌은 항해를 멈추지 않습니다.
- **M** 또는 음표 버튼을 켜면 방향감 있는 전환음, 수집·콤보 상승음, 충돌음과 조용한 배경 리듬이 재생됩니다. 배경 리듬은 일시정지·탭 이탈·종료 때 멈추고 재개 준비 시간이 끝난 뒤 다시 시작합니다.
- 시스템의 모션 감소 설정에서는 별빛 이동·파동 확대·점수 이동과 카드 진입 애니메이션을 줄이고, 충돌 즉시 결과를 보여줍니다. 실행 중 설정 변경도 반영합니다. 시각 효과 개수에는 상한이 있으며, 장식용 난수는 파편 생성과 분리되어 있습니다.
- 기존 충돌 판정과 에너지 배수·속도 상한을 유지하면서 접근 패턴, 퍼펙트 보너스와 보호막을 추가했습니다. 외부 이미지나 음원 다운로드는 사용하지 않습니다.

## 확인 및 배포

```sh
npm test
npm run build
```

`wrangler.jsonc`는 Cloudflare Workers 정적 자산 배포용입니다. Wrangler는 개발 의존성으로 포함되어 `npm run dev:cloudflare`(빌드 후 Workers 런타임 로컬 실행), `npm run check:cloudflare`(배포 설정 dry-run, 로그인 불필요), `npm run deploy:cloudflare`(배포, `wrangler login` 필요)를 사용합니다. 이 프로젝트 자체에는 계정 정보나 비밀 키가 포함되지 않습니다.

충돌 판정·전환 입력·난이도·배수 상한 외에 교차 패턴 간격, 퍼펙트 판정·보상, 보호막 소모·재충전·일시정지, 섹터 변화, 효과 상한·모션 감소, 성운 텍스처·캐시·미지원 환경, 오디오 정리를 Node.js 기본 테스트 러너로 검증합니다. 같은 시드에서 모션 설정에 관계없이 점수·수집 결과가 같은지 확인하고, 여러 시드의 후반 패턴을 최대 프레임 간격으로 진행해 보호막에 의존하지 않는 회피 경로도 확인합니다.
